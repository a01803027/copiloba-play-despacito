# Empieza aquí

La guía actual está en **[MAC_SETUP.md](MAC_SETUP.md)**, en español y desde cero.

Ahora el motor puede reproducir en Mac mediante CoreAudio. Las instrucciones
anteriores que describían el Mac como «solo offline» quedaron superadas.

El objetivo es componer música con tu danza, no asignar una nota a cada altura.
Primero prueba el compositor sin cámara; después usa el mismo sistema con ella.
No necesitas leer C++ para hacerlo.

Si quieres entender qué se conservó y qué cambió, lee
[la explicación del sistema existente](docs/EXISTING_SYSTEM_EXPLAINED.md).
Para saber qué se probó realmente, consulta
[el informe de implementación](docs/IMPLEMENTATION_REPORT.md).
